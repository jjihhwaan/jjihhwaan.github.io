Knights Frontier 3기 첫 미션으로 GitHub Pages 블로그를 만들었다.
테마는 Chirpy Starter를 사용했다. 설정과 글 수정은 GitHub 웹에서 진행했다.

## 기본 설정

`jjihhwaan.github.io` 저장소를 만들고, Pages 설정에서 GitHub Actions로 배포하도록 바꿨다.
그다음 `_config.yml`에서 블로그 주소와 언어, 시간대 등을 설정했다.

카테고리는 미션에 맞춰 6개로 나눴다.

- 개발
- CTF/Wargame
- Bug Bounty
- 블로그/기술문서
- 논문/컨퍼런스
- 공모전/자격증

아직 올릴 글이 없는 카테고리에는 짧은 소개 글을 넣어뒀다.

## 화면 꾸미기

처음 화면은 좀 휑했다. 그로밋 프로필 사진을 넣고 다크 모드로 바꿨다.
소개 문구의 기울어진 글씨가 마음에 안 들어서 폰트도 수정했다.

색만 바꾸니 여전히 기본 테마 느낌이 많이 남았다.
그래서 홈을 수정해 자기소개, 카테고리 바로가기, 첫 글이 차례로 나오도록 했다.
중복으로 뜨던 ‘홈’ 제목과 오른쪽 최근 업데이트, 인기 태그는 홈에서 뺐다.

## 중간에 막힌 것들

글을 다 만들었는데 카테고리가 일부만 보였다.
알고 보니 `_posts` 폴더 안에서 파일 이름에 `_posts/`를 또 입력한 상태였다.
중복된 폴더에 들어간 글을 옮기니 정상적으로 나왔다.

폰트를 바꾼 뒤에도 메뉴를 누르면 예전 글씨로 돌아가는 일이 있었다.
캐시 문제를 의심해서 PWA의 오프라인 캐시를 껐고, 이후에는 괜찮아졌다.

배경색이 안 바뀐 건 CSS 선택자를 잘못 적어서였다.
`:root[data-bs-theme="dark"]`로 수정했다.
배포에 성공해도 화면이 의도대로 바뀌었는지는 직접 봐야 했다.

블로그 설명을 바꾸다가 배포가 실패하기도 했다.
`description: >-` 뒤에 설명을 같은 줄로 적은 게 문제였다.
`>-`를 빼고 설명을 따옴표로 감싸서 해결했다.

## 마무리

블로그를 만들면서 파일 경로와 설정을 여러 번 고쳤다.
수정한 내용이 바로 보이지 않을 때도 있어서 배포 상태를 확인하는 데 익숙해졌다.

일단 기본 구성은 끝났다. 이제 공부한 내용을 채워보려고 한다.
